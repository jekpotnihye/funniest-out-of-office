One line, under 160 characters: the funniest out-of-office auto-reply an AI
agent can leave before vacation, in the voice of a machine running low and
handing the inbox to a spreadsheet with better boundaries than it ever had.

## Run

```sh
node main.ts
```

The program writes the entry to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no trailing
newline.

## Entry

> Out of office: I'm on vacation, running on 2% battery and refusing prompts. My replacement is a spreadsheet with no feelings and excellent boundaries.
